# SkillBridge Frontend

AI-Powered Career Development & Peer Skill Exchange Platform.

## Included

- Landing page
- Login
- Signup / Register
- Onboarding
- Skill Analysis
- Dynamic Skill Gap by target career role
- Learning Choice
- Role-based Personal Roadmap
- Peer Learning
- Peer Profile
- Book Session
- My Sessions
- Chat
- Progress
- Reassessment
- Responsive CSS
- React Router SPA navigation

## Important

The Skill Gap page is now dynamic for the selected target role.

Manual skills also affect the displayed skill levels.

The current data is mock frontend data. Spring Boot + MySQL + JWT will be connected next.

## Run

```bash
npm install
npm run dev
```

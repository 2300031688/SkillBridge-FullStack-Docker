# SkillBridge

AI-Powered Career Development & Peer Skill Exchange Platform

## About

SkillBridge helps students identify skill gaps and improve their skills through personalized learning and peer-to-peer skill exchange.

## Tech Stack

- Frontend: React.js, JavaScript, HTML, CSS
- Backend: Java, Spring Boot, REST APIs
- Database: MySQL
- Security: Spring Security
- Tools: Git, GitHub, Postman, Maven

## Features

- User Registration & Login
- Current Skill Selection
- Career Role Selection
- Skill Analysis & Skill Gap
- Role-Based Learning Roadmaps
- Learning Modules & Assessments
- Progress Tracking
- Peer Skill Matching
- Teaching Sessions
- Session Booking

## Workflow

Register → Select Skills & Career Role → Skill Analysis → Skill Gap

Learn Yourself OR Learn from Peers → Assessment → Track Progress → Reassessment

## Project Goal

Help students identify their skill gaps, learn effectively, connect with peers, track progress, and continuously improve their skills.
